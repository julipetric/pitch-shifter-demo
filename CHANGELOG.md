# Changelog

All notable changes to this project are documented here.

The format is inspired by [Keep a Changelog](https://keepachangelog.com/). Entries are grouped by
milestone and dated from the git history.

## [2026-11-12] Containers, tests, CI and documentation

### Added
- `docker-compose.yml`, `backend/Dockerfile` and `frontend/Dockerfile`: `docker compose up --build` serves the app on one port, with nginx proxying `/api`, `/health`, `/diagnostics` and `/swagger` to the backend.
- xUnit test project `backend/pitch-shifter-demo-backend.Tests` and `backend/PitchShifterDemo.sln`, covering parameter validation, sample resolution, the fallback tone, metadata, start offsets and the HTTP endpoints.
- Angular specs for the time pipe, `AudioApiService`, `AudioFacadeService`, `WaveformFrequencyService` and `AppComponent`, with a Karma configuration (`CHROME_BIN`, `ChromeHeadlessNoSandbox`) and an `npm run test:ci` script.
- GitHub Actions workflow (`.github/workflows/ci.yml`): backend build and tests, frontend build and tests on Node 20 and 22, and a Docker Compose smoke test that requests a processed MP3 stream.
- `Cors:AllowedOrigins` and `HttpsRedirection:Enabled` configuration keys for the backend.
- `AUDIO_API_BASE_URL` build-time constant for production frontend builds (`ng build --define`).
- `docs/DEPLOYMENT.md` (Docker and Azure deployment, replacing the personal notes that lived in `scripts/`), screenshots in `docs/images/`, an MIT `LICENSE`, and a rewritten README.
- Public-domain sample recording (*Maple Leaf Rag*, U.S. Air Force Band) with its license and source documented in `backend/pitch-shifter-demo-backend/Content/Samples/README.md`.

### Changed
- The frontend resolves the API base URL against the page origin; an empty base URL targets the origin that served the app.
- Production builds no longer point at a fixed hosted backend.
- `backend/README.md`, `frontend/README.md`, `docs/ARCHITECTURE.md`, `docs/STACK.md` and the Azure guides describe the code as it is: waveform analysis, minimal API endpoints, CORS configuration and Windows App Service hosting.
- `.cursor/` (editor tooling generated by `openspec init`) is no longer tracked.

### Removed
- The original sample recording, which could not be redistributed, and its history. The git history was rewritten to drop it, so existing clones need a fresh `git clone`.

## [2026-02-26] Audio facade

### Changed
- Extracted `AudioFacadeService` from `AppComponent`; it owns the pitch, tempo and preserve-pitch parameters and exposes the track metadata as an observable.

## [2026-02-24] Frontend refactoring

### Added
- `AudioApiService` (stream URL building and metadata requests), `FormatTimePipe` and the `AUDIO_API_BASE_URL` injection token.
- `WaveformFrequencyService`: chunked FFT that finds the dominant frequency per time segment, with an explanatory note in `waveform-frequency.service.md`.

### Changed
- `WaveformSnippetComponent` delegates frequency analysis to the new service and colours bars progressively as chunks finish.
- General clean-up of `AppComponent` and its styles.

## [2026-02-23] Waveform comparison

### Added
- Waveform view (`WaveformSnippetComponent`, WaveSurfer.js): original and processed audio side by side, with bars coloured by dominant frequency (#6).

### Fixed
- Dependency and runtime fixes for deployment builds: NAudio.Core with a managed NLayer MP3 decoder and an `AssemblyResolve` redirect for legacy NAudio references.

## [2026-02-22] Backend, streaming and pitch/tempo control

### Added
- ASP.NET Core 8 Minimal API with `/health`, launch settings, Azure deployment guide and Swagger (#2, #3).
- Audio streaming from a configurable samples folder (`Audio:SamplesPath`, `Audio:DefaultFileName`) with a generated fallback tone (#3).
- Frontend audio transport: play/pause, seek, volume and track metadata from `/api/audio/metadata` (#4).
- `/diagnostics/audio` endpoint and bundling of sample files into build output.
- Pitch and tempo control (#5): `AudioProcessingParameters` validation, `IAudioProcessor` with a SoundTouch implementation, MP3 encoding with LAME, `startSeconds` offsets, a preserve-pitch toggle and the matching sliders.
- Angular frontend boilerplate (#1), Azure Static Web Apps deployment guide and OpenSpec change artifacts under `openspec/`.

## [2026-02-21] Initial setup

### Added
- Repository scaffolding, baseline documents and developer bootstrap scripts (`scripts/dev-setup.ps1`, `scripts/dev-setup.sh`).
